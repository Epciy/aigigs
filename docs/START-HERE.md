# How to start with Claude Code

1. Make a new private GitHub repo `aigigs` and clone it.
2. Copy everything from this kit into the repo root:
   - `CLAUDE.md`
   - `docs/PLAN.md`
   - `.claude/skills/` (all four folders)
3. Open the repo in Claude Code and send your first message:

```
Read CLAUDE.md and docs/PLAN.md. Then plan milestone M0 (setup) and wait for my OK before writing code.
```

4. For each next milestone:

```
M0 is done. Plan milestone M1 using the build-feature skill. Wait for my OK.
```

5. Before M6 and M8, answer the open questions in PLAN.md section 13 first.

Tip: when Claude Code finishes a milestone, try the "Done when" step yourself before moving on.
